API Reference

Base: the SecondNurse origin. All bodies are JSON. AI endpoints return 503 with an explanatory error when MODEL_API_KEY / SECONDNURSE_MODE=live are not configured — they never return fabricated data.

GET /api/health

{ "status": "ok", "live_meta_api": true,
  "models": { "reasoning": "muse-wonder-1.0", "segmentation": "sam-3.1" },
  "mode": "live" }

POST /api/compile

Compile protocol text into a StepGraph via Muse Wonder. Rate-limited.

→ { "protocol_text": "1. Wash hands for 20 seconds…", "name": "Home exchange protocol" }
← { "name": "…", "source": "muse-wonder-live", "step_count": 7,
    "steps": [ { "id": "step-1", "title": "…", "objects": ["…"],
                 "forbidden_contacts": [], "min_seconds": 20 } ],
    "global_rules": [ … ] }
ErrorMeaning
400Missing/invalid JSON, or non-string fields.
429Rate limit (30/min per client).
503Meta API not configured.

POST /api/segment-live

Segment one camera frame for up to five concept prompts. One SAM 3.1 request per prompt; masks decoded server-side; hand∩tip overlap measured when both are found.

→ { "image": "data:image/jpeg;base64,…",
    "prompts": ["gloved hand", "red connector", "blue cap", "sterile field mat"] }
← { "live": true, "model": "sam-3.1", "latency_ms": 2400,
    "results": [ { "prompt": "red connector", "canonical": "sterile_tip",
                   "frame_w": 640, "frame_h": 360,
                   "boxes": [ { "x": 452, "y": 196, "w": 30, "h": 36,
                                "confidence": 0.93, "mask": { "w": 30, "h": 36 } } ] } ],
    "touch": { "overlap_px": 0.0, "method": "mask" } }
  • canonical maps prompts to rule objects: hand, sterile_tip, cap, field.
  • touch.method is mask for true pixel overlap, box only if a mask payload could not be decoded.
  • Errors: 400 bad body/image, 429 rate limit (20/min), 503 not configured, 502 upstream SAM failure.

POST /api/evaluate

Evaluate a recorded trace of tracked frames against the breach rules (used for testing and offline analysis).

→ { "frames": [ { "t": 0.0, "step": 1,
                  "objects": { "hand": {"x":…,"y":…,"w":…,"h":…},
                               "sterile_tip": {…}, "cap": {…} },
                  "field": {"x":…,"y":…,"w":…,"h":…} } ] }
← { "events": [ { "type": "TOUCH", "t": 1.2, "detail": "…", "overlap_px": 225 } ],
    "event_count": 1, "compliance_score": 75 }

Rules: overlap sustained ≥0.3s of trace time fires TOUCH; cap centroid outside the field fires FIELD; a step jump fires ORDER. Score is 100 − 25 per event.

POST /api/segment

Single-prompt convenience route retained for integrations. Live segmentations should use /api/segment-live with a frame; without a frame or configuration it returns 503.

Conventions

  • Coordinates are source-frame pixels, top-left origin. The front end converts to percentages for overlays.
  • Timestamps are seconds within a session/trace.
  • Error bodies are always { "error": "human-readable reason" }.
