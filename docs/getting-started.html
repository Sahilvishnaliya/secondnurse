Setup & First Watch

SecondNurse runs live only. You need a Meta Model API key. Without one, the app loads, the camera opens, and every AI endpoint returns 503 configuration required — by design.

Requirements

  • A Meta Model API key with access to muse-wonder-1.0 and sam-3.1.
  • A phone or webcam that can see the whole bench from above.
  • The training kit: red connector tip, blue cap, sterile field mat, gloves, tubing, fluid-bag stand-in.
  • A modern browser with camera permission (HTTPS or localhost).

Configure the API key

On Vercel

  1. Open the project → Settings → Environment Variables.
  2. Add MODEL_API_KEY with your key (Production).
  3. Add SECONDNURSE_MODE with value live.
  4. Redeploy. The header pill switches from “key required” to “Meta API: live”.

Locally

pip install -r requirements.txt
cp .env.example .env   # set MODEL_API_KEY and SECONDNURSE_MODE=live
python app.py          # http://127.0.0.1:5000

Keys are server-side environment variables only. They are never committed and never sent to the browser.

Set up the bench

  1. Mount the camera overhead, roughly 50–80 cm above the bench, framing the sterile mat, connector, supplies, and both hands. See IoT Devices for mounts and camera options.
  2. Light it evenly. Avoid backlight and harsh shadows; masks are only as good as the frame.
  3. Use the colour-coded kit. Big, matte, distinct parts (red tip, blue cap) are what make zero-shot SAM prompts reliable.
  4. Lay out supplies inside the sterile field before you start.

Your first live watch

  1. Open the app and read the header: it must say Meta API: live.
  2. In the live console, choose Enable camera and allow permission.
  3. Choose Analyze one frame. Within a few seconds, SAM boxes appear over the hand, connector, cap, and field, and the Live Results table fills with what was found, confidence, mask size, and latency.
  4. Choose Start live watch. A frame is analyzed every 3 seconds.
  5. Perform the exchange. If your hand overlaps the sterile tip on two consecutive analyzed frames, the procedure stops: red alert, voice correction, score drop, logged event.
  6. End with Reset session when acknowledged and corrected.

Compile your protocol first (recommended)

Go to Protocol Compiler, paste the procedure you were trained on, and compile it. The checklist in the live console is generated from that graph — steps, objects, forbidden contacts, and minimum disinfection times — so the system watches your protocol, not a generic one.

What “working” looks like

SignalMeaning
Header pill: “Meta API: live”Key configured; Muse + SAM reachable server-side.
Boxes track your hand as you moveSAM prompts are matching the kit in your lighting.
Live Results updates each frameReal responses, with per-object confidence and latency.
A deliberate touch fires the alertEnd-to-end: camera → masks → geometry → rule → alert.

If a deliberate touch does not fire, work through FAQ & Troubleshooting — it is almost always framing, lighting, or a prompt/kit colour mismatch.
