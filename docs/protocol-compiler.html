Protocol Compiler

Hardcoded checks are a demo trick. The Protocol Compiler turns any written sterile procedure into executable vision checks — the anti-hardcoding core of SecondNurse.

What goes in, what comes out

In: plain protocol text — the steps as a patient was taught them, numbered or not.

Out: a StepGraph JSON document:

{
  "name": "Home exchange protocol",
  "source": "muse-wonder-live",
  "step_count": 7,
  "steps": [
    { "id": "step-1", "title": "Wash and fully dry your hands…",
      "objects": ["hand hygiene"], "forbidden_contacts": [], "min_seconds": 20 }
  ],
  "global_rules": [
    { "a": "hand", "b": "sterile connector tip", "rule": "TOUCH" },
    { "a": "cap", "b": "outside sterile field", "rule": "FIELD" }
  ]
}

How compilation works

  1. Protocol text is sent to Muse Wonder (muse-wonder-1.0) with a strict JSON-only instruction: steps, required objects per step, forbidden contacts, minimum seconds where the text states a duration.
  2. The response is validated as structured JSON with a non-empty steps array. Anything else is rejected, not repaired silently.
  3. The graph drives the UI checklist and is the same schema the server-side rule evaluator consumes for ORDER checks.
  4. Two global sterile rules are always present (TOUCH, FIELD) even if a given protocol text forgets to state them — they are properties of sterile technique, not of one document.

Writing a compilable protocol

  • One action per line. “Wash hands, dry them, then glove” compiles worse than three lines.
  • Name objects concretely. “The connector tip” beats “it”; object extraction keys on named things.
  • State durations numerically. “Scrub for 20 seconds” yields min_seconds: 20; “scrub well” yields nothing enforceable.
  • State prohibitions explicitly. “Never touch the sterile connector tip” becomes a forbidden-contact rule.
  • Use your own words. Do not paste a manufacturer's proprietary manual. Write the procedure as taught, from public guidance, in your own phrasing.

Trust, but verify the graph

A language model can invent or drop a step. The compiler UI therefore shows the full generated graph — cards per step with object chips, forbidden-contact chips, and time chips, plus the raw JSON. Read it before a session. If a step is wrong, fix the source text and recompile; the graph is only ever as good as the document and the human who reviewed it.

API

POST /api/compile with { "protocol_text": "…", "name": "…" } returns the StepGraph, or 503 when the Meta API is not configured, or 400 for malformed input. Compilation is rate-limited per client. See API Reference.

Why a compiler, architecturally

Every prior procedure-monitoring system ships with per-procedure engineering: new dataset, new training, new deployment. Foundation models invert that. SAM segments anything named; Muse compiles anything written. The procedure becomes data, and SecondNurse — the watcher — stays the same program across dialysis, infusion, catheter, and wound-care protocols.
